# Фінальний проєкт: Реляційні бази даних (GoIT)

## 📌 Опис проєкту
Цей фінальний проєкт присвячений роботі з реляційними базами даних та аналізу статистичних даних за допомогою SQL і Python (Google Colab). У проєкті опрацьовується датасет інфекційних захворювань (`infectious_cases`), який містить інформацію про різноманітні хвороби за різними країнами та роками.

---

## 🗂 Структура репозиторію
- `goit_rdb_final_project.ipynb` — Google Colab ноутбук з повним виконанням усіх 5 завдань проєкту (код, SQL-запити, функції та результати).
- `infectious_cases.csv` — вихідний набір даних, що використовується для аналізу.
- `README.md` — документація та опис проєкту.

---

## 🛠 Етапи виконання проєкту

### Завдання 1: Завантаження даних
- Створено схему `pandemic` у базі даних та обрано її за замовчуванням.
- Імпортовано дані з файлу `infectious_cases.csv` та проведено попередній огляд структури таблиці.

### Завдання 2: Нормалізація таблиці до 3-ї нормальної форми (3NF)
- Створено довідник країн (`entities`) з унікальними комбінаціями назв (`Entity`) та кодів (`Code`).
- Створено нормалізовану таблицю фактів (`infectious_cases_normalized`), де замість дублювання текстових назв країн використовується зовнішній ключ (`entity_id`).
- Усі числові поля очищено від порожніх значень та переведено в числовий формат (`NUMERIC`).

### Завдання 3: Аналіз даних
- Здійснено групування даних за країнами.
- Для показника скажених захворювань (`number_rabies`) пораховано:
  - Середнє значення (`AVG`) з округленням до 2 знаків.
  - Мінімальне (`MIN`) та максимальне (`MAX`) значення.
  - Суму (`SUM`).
- Результати відсортовано за середнім значенням у порядку спадання та виведено топ-10 рядків.

### Завдання 4: Побудова колонки різниці в роках
- За допомогою вбудованих SQL-функцій для кожного запису сформовано:
  - Дату першого січня відповідного року (`1st January`).
  - Поточну дату.
  - Атрибут, що обчислює різницю в роках між поточною датою та датою початку року.

### Завдання 5: Побудова власних функцій
- Реалізовано скалярну функцію для обчислення різниці в роках від заданого року до поточної дати.
- Створено функцію для розрахунку середньої кількості захворювань за довільний період (з перевіркою дільників `12` для місяців, `4` для кварталів та `2` для півріч).
- Успішно застосовано обидві створені функції у запитах на відфільтрованих числових даних.
